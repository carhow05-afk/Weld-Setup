Open index.html to preview on a computer. For installation on Android, upload all five app files (index.html, manifest.webmanifest, sw.js, icon192.png, icon512.png) to the root of a GitHub repository. In Settings > Pages, select Deploy from a branch, main, / (root), then Save. Open the published HTTPS address on your phone in Chrome. Wait for the first page to load, then choose Install app or Add to home screen in Chrome's menu. After loading online, test offline in airplane mode. No account or network is required for the calculator itself. Settings are local to the device. Generic starting estimates only; the exact operating manual was not verified. Check it and the consumable label before connecting leads. Never rely on this tool for safety-critical welds.
